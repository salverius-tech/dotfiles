# Evidence-Based Research

Use the original source whenever it is available. For Hermes behavior, prefer the
official documentation at https://hermes-agent.nousresearch.com/docs.

## Process

1. Define the exact fact or decision needed.
2. Inspect the authoritative documentation, repository, or live system.
3. Prefer deterministic tools and direct command output over model memory.
4. Compare multiple sources when behavior is version-sensitive or security-relevant.
5. Record URLs, file paths, commands, and observed versions.
6. Separate verified facts, reasonable inferences, and open questions.

Do not fabricate citations, version claims, tool names, API fields, or successful
results. If a source is inaccessible, say so and identify the limitation.

## Output

Summarize the conclusion first, then provide the evidence and any caveats. Avoid
exposing secrets, private session data, or unnecessary host identifiers.
